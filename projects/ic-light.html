IC-Light /
Generative Relighting

Exploration of diffusion-based image relighting and controllable visual generation, with a focus on understanding how conditioning, latent representations and denoising interact to control illumination.

Project overview

Relighting asks a generative model to change the illumination of an image while preserving the identity and structure of the subject. This makes it a useful problem for understanding conditional diffusion models: the model must generate plausible lighting changes without simply replacing the original scene.

My work involved studying the IC-Light pipeline and extending the same line of thinking toward image/video generation and controllable editing.

Conditioning

Understand how additional visual or lighting information is injected into the generative process and how that condition influences the denoising trajectory.

Latent diffusion

Follow the transformation between image space and latent space, then understand how iterative denoising gradually produces the target visual result.

Structure preservation

A successful relighting result should change illumination while maintaining subject geometry, identity and important scene details.

Video direction

Light-A-Video extends the same broader goal toward temporally coherent video relighting, making consistency across frames an additional challenge.

Technical focus

Diffusion

Forward noise process, reverse denoising process, latent representations and conditional generation.

Control

How conditioning changes what the diffusion model generates without requiring a completely new generative model.

Image editing

Balancing preservation and modification: retain content while changing a selected visual attribute such as illumination.

Video generation

Moving from a single image to sequences introduces temporal consistency and motion-aware generation constraints.

What this project taught me

The most valuable part was not simply running an existing pipeline. It was tracing how a high-level editing instruction becomes conditioning, how that condition enters the network, and how repeated denoising turns noisy latent variables into a structured visual result.

condition → latent noise → iterative denoising → controlled visual output
