Financial Report AI /
Terminology Governance

An applied NLP and document-processing project focused on extracting terminology from financial reports, improving consistency and supporting intelligent governance workflows.

Project overview

Financial reports contain large amounts of semi-structured text, recurring domain terms and inconsistent terminology. The project explored how data processing, semantic representation and large language models can be combined to make terminology governance more systematic.

The emphasis was on turning heterogeneous report data into a workflow that can be inspected, standardized and reused.

Data engineering

Use Pandas and OpenPyXL to process tabular data and spreadsheet-based financial materials into structured records.

Semantic similarity

Use Sentence-BERT style embeddings to compare terms by meaning rather than relying only on exact string matching.

LLM assistance

Use language models for terminology analysis, normalization suggestions and more flexible text understanding.

Governance output

Produce standardized terminology and machine-readable results that can support downstream review and document workflows.

Technical focus

Pandas

Cleaning, joining, filtering and transforming report-derived data.

OpenPyXL

Reading and writing Excel workbooks while preserving a practical document workflow.

Sentence-BERT

Represent terms or phrases as dense vectors and compare semantic similarity.

LLM

Use generative models as a flexible language reasoning component alongside deterministic processing.

What this project taught me

The main engineering lesson was that useful enterprise AI rarely comes from a single model. Reliable workflows often combine deterministic data processing, semantic retrieval or similarity, and generative models where open-ended language understanding is valuable.

structured data + semantic representation + LLM reasoning → usable workflow
